Power BI Healthcare  Analysis Dashboard
Project Overview

This project presents an interactive Power BI dashboard designed to analyze healthcare patient waitlist data.
The dashboard enables stakeholders to monitor waitlist trends, identify operational bottlenecks, and evaluate patient wait times across different case types, medical specialties, age groups, and waiting time bands.
The solution supports both high-level performance monitoring and detailed operational analysis to aid data-driven healthcare decision-making.

Dashboard Structure
Summary Analysis
Overview

The Summary Analysis view provides a consolidated snapshot of overall waitlist performance.
It is designed to support quick interpretation of key metrics and trend identification.

Key Insights

Overall waitlist metrics for the latest reporting period
Comparison of current waitlist figures with previous periods
Patient distribution by case type (Day Case, Inpatient, Outpatient)
Trend analysis of waitlist volume over time
Time-band analysis based on waiting duration
Specialty-wise average and median wait times


Objective

To provide a high-level understanding of system performance and highlight key trends at a glance.

Detailed Analysis
Overview

The Detailed Analysis view supports deeper exploration of waitlist data through interactive filters and structured tables.

Key Insights

Interactive slicers for:
Archive Date
Case Type
Age Profile
Specialty
Time Bands

Detailed tabular breakdown of waitlist counts

Analysis by case type and waiting duration
Drill-down functionality for granular investigation
Clear total aggregations to support accurate comparisons

Objective

To enable detailed operational analysis, specialty-level comparison, and informed decision-making.

Navigate between dashboard views using the report tabs
